# えいけんタウン

> **英検準1級・2級・準2級・3級・4級・5級クエスト** — クイズに答えて、街を育てよう!

英検準1級・2級・準2級・3級・4級・5級の練習と街づくりを組み合わせた、単一 HTML ファイルのブラウザゲームです。模擬試験や合格の保証ではありません。

🔗 デモ: https://keima-tech.github.io/eiken-town/

変更履歴は [CHANGELOG.md](CHANGELOG.md) を参照してください。

---

## 1. 概要

- **タイトル**: えいけんタウン | 英語で街づくり
- **形式**: 単一 HTML ファイル（ビルド不要）。Three.js とフォントは外部配信元から読み込むため、完全なオフライン動作は保証しません
- **対象**: 英検5級・4級・3級・準2級・2級・準1級レベルの学習者（小学生〜高校生向け）
- **コンセプト**: 英検5級・4級・3級・準2級・2級・準1級の6分野（たんご・ぶんぽう・かいわ・じゅんじょ・ちょうかい・さくぶん/どっかい、3級・準2級・2級は本番形式の英作文を加えた7分野）のクイズに答え、コインを獲得して街を発展させる
- **保存**: ブラウザの localStorage に自動保存（サーバー不要、級ごとに個別保存）

## 2. はじめかた

### 2.1 開始

1. `eiken-town.html` をブラウザで開く
2. タイトル画面で練習する級（英検5級 / 英検4級 / 英検3級 / 英検準2級 / 英検2級 / 英検準1級）を選ぶ
3. **「▶️ はじめる!」** をタップ
4. **街の名前をつける** 画面が表示される（最大12文字）
   - サジェストから選ぶことも、自由に入力することもできる
   - 空欄でスキップも可能
5. 6ページのチュートリアルが自動表示される（「スキップ」で飛ばせる）
6. 街画面（scr-town）に移動

### 2.2 級の切り替え

- 設定（⚙️）の「練習する級を選ぼう」から級を切り替えられる
- 級ごとに別の街・コイン・記録が保存され、切り替えても互いに影響しない

### 2.3 継ぎから（再開）

- 保存データがある場合、タイトル画面のボタンが **「▶️ つづきから!」** に変わる
- タップすると前回の状態から再開

### 2.4 別のブラウザから引っ越す

- タイトル画面の **「📂 ファイルからつづきをよみこむ」** をタップし、別ブラウザで保存したJSONファイルを選択
- 確認後に全ての級のデータが復元され、ボタンが **「▶️ つづきから!」** に変わる

## 4. 建物を建てる

### 4.1 建物パレット

**「🏗️ こうじする」** をタップすると、建てられる建物の一覧が表示される。

| 建物 | 絵文字 | カテゴリ | コイン | 解放条件 | クイズ種別 |
|------|--------|----------|--------|----------|------------|
| 図書館 | 📚 | たんご | 無料 | — | 単語・文法の穴埋め選択 |
| 学校 | 🏫 | ぶんぽう | 💰30 | 図書館 | 文法選択クイズ |
| カフェ | ☕️ | かいわ | 💰60 | 学校 | 会話パターン選択 |
| 駅 | 🚉 | じゅんじょ（準1級はちょうぶんほきゅう） | 💰100 | カフェ（準1級は図書館の次） | 単語並べ替え / 語句の組選択（準1級は長文補充） |
| 公園 | 🌳 | ちょうかい | 💰150 | 駅 | リスニングクイズ |
| お花屋さん | 🌷 | さくぶん（3・4級はどっかい） | 💰200 | 公園 | 英作文（5級）/ 読解（3・4級） |
| さくぶん工房 | ✍️ | さくぶん（3級・準2級・2級・準1級のみ） | 💰250 | お花屋さん | 英作文（本番形式・1問） |
| まとめ塾 | 📝 | ようやく（準2級・2級・準1級のみ） | 💰300 | さくぶん工房 | 要約（本番形式・1問） |
| 復習タワー | 🗼 | ふくしゅう（全級） | 無料 | — | まちがえた問題のふくしゅう専用（町のランク・建物数には数えない） |

- **順番に解放**: 図書館→学校→カフェ→駅→公園→お花屋さん（→3級・準2級・2級・準1級のみ さくぶん工房→準2級・2級・準1級のみ まとめ塾）。前の建物を建てると次が解放され、一度解放すると前の建物を撤去しても解放状態は残る
- **復習タワーは最初から無料**: 図書館と同様、はじめから建てられる
- **コインが足りない** 場合もロック表示される
- 1種類の建物は最大1つだけ建てられる

### 4.2 道路

- **コスト**: 💰10 / マス
- 建物の上には引けない
- **効果**:
   - 通常クイズを完了すると、街全体の道路に隣接する建物数 × 2 コインが加算される（正解数に関係なく1回、復習は対象外）
  - 道路がつながるとカラフルな車（最大4台）が走り出す

### 4.3 かざり（装飾）

パレット下部の「🌼 かざり」から選べる、見た目専用のアイテム。クイズやコイン獲得への効果はない。

| かざり | 絵文字 | コイン |
|--------|--------|--------|
| 花壇 | 🌼 | 💰5 |
| ベンチ | 🪑 | 💰10 |
| 噴水 | ⛲ | 💰20 |
| 街灯 | 💡 | 💰10 |
| 案内板 | 🪧 | 💰5 |
| ブランコ | 🛝 | 💰15 |
| ポスト | 📫 | 💰5 |
| 時計台 | 🕰️ | 💰20 |
| バス停 | 🚏 | 💰10 |

- **解放条件なし**: 最初から置ける（コインが足りない場合は選べない）
- **配置ルール**: 建物・道路・他のかざりがあるマスには置けない。1マスに1つのみ
- **撤去**: かざりをタップ→確認ダイアログで撤去（コインは戻らない）

### 4.4 建設手順

1. 「🏗️ こうじする」をタップ
2. 建物（または道路・かざり）を選択
3. 画面下部に「📍を置く場所をタップ!」と表示される
4. 空いているマスをタップ
5. 確認ダイアログで建設を確定（or やめる）
6. 建物が出現し、コインが消費される

> **道路の連続建設**: 道路を選択中は連続タップでどんどん道を引ける

## 5. 建物のレベルアップ

### 5.1 レベル構造

各建物は **Lv.1 → Lv.2 → Lv.3** の3段階。

| レベル移行 | 必要正解数 | 必要コイン | 出題難易度 |
|------------|------------|------------|------------|
| Lv.1 → Lv.2 | 6問 正解 | 💰40 | d=1 のみ → d=1〜2（中心は2） |
| Lv.2 → Lv.3 | 16問 正解 | 💰100 | d=1〜2 → d=2〜3（中心は3） |

### 5.2 レベルアップの方法

1. 建物をタップ → メニューが開く
2. 「⬆️ レベルアップする」ボタンが有効になればタップ
3. コインを消費してレベルアップ

> **注意**: 正解数とコインの**両方**が揃っていなければレベルアップできない

### 5.3 難易度の仕組み

- 各問題に難易度（d: 1, 2, 3）が設定されている
- 建物レベルに応じて、出題される難易度の範囲が変わる
- Lv.3 になると難しい問題（d=3）が多く出る

## 6. クイズのルール

### 6.1 基本流れ

1. 建物をタップ → 「▶️ クイズをはじめる!」をタップ
2. **通常クイズ**: 5問出題（お花屋さんは5級で2問、3・4級・準2級・2級でレベルに応じて2〜5問、さくぶん工房・まとめ塾は1問）
3. 各問に正解 or 不正解で結果が表示
4. 「つぎへ ▶」で次の問題へ
5. 最後に結果画面（scr-result）が表示される

### 6.2 コイン獲得

| 種別 | コイン |
|------|--------|
| 通常正解 | 3 + 2 × 難易度（d=1→5, d=2→7, d=3→9） |
| 連続正解ボーナス | 2回連続から +2 ずつ（最大 +8） |
| パーフェクトボーナス | +10（全問正解 & 3問以上） |
| 道路ボーナス | 隣接建物数 × 2 |
| 復習正解 | 4 コイン固定 |
| 作文（お花屋さん） | 5 + チェック項目数 × 5 |

### 6.3 連続正解（ストリーク）

- 連続で正解すると 🔥 のカウンターが表示される
- 2回以上連続で正解するとボーナスコインが加算
- 不正解でリセットされる

## 7. 問題の種類別详解

### 7.1 選択式クイズ（図書館・学校・カフェ）

- **形式**: 英文の空欄を4つの選択肢（A〜D）から選ぶ
- **対象**: たんご（語彙）・ぶんぽう（文法）・かいわ（会話）
- **解き方**:
  1. 問題文を読む（空欄は `_ _` で表示）
  2. 4つの選択肢から正解を選ぶ
  3. 正解 → 緑色のフィードバック + 解説
  4. 不正解 → 赤色のフィードバック + 正解表示 + 解説

### 7.2 語句の並べ替えクイズ（駅）

- 日本語の文と番号付きの語句を読み、正しい英文の順序を考える
- 指定された2つの位置に入る語句の番号の組を、4択から選ぶ
- 語句の番号は固定。回答後に完成文・正しい組・解説を確認できる
- 旧版の復習問題では、単語カードを順にタップして並べる形式も出題される

### 7.3 リスニングクイズ（公園）

- 会話への応答、絵に合う英文、対話の内容、英文の内容などを級別に練習する
- 音声と質問を聞いて、3択または4択から回答する。応答・絵の問題では選択肢も音声で聞き、番号で答える
- **音声再生**:
  - 自動再生または「再生」ボタンで2回再生。追加の練習用リプレイも可能
  - 難易度に応じて再生速度が変わる
  - 回答時や画面移動時には再生を停止する
  - 音声非対応・再生失敗時は文章を表示する。この場合は音声練習ではなく読んで回答する
- 回答後は、正誤にかかわらず「音声の文章をみる」で内容を確認できる
- 旧版の復習問題には、絵を選ぶ形式や従来の会話選択式も含まれる

### 7.4 英作文・読解クイズ（お花屋さん）

**5級（英作文）**:

- **形式**: 英語のトピックに対して短い英文を書く（目標: 5〜15語）
- **1セッションあたり2問**（他の建物は5問）。追加の練習モードで、本番の試験ではありません
- **解き方**:
  1. 英語のトピックと日本語の説明を読む
  2. ヒントフレーズを参考にする
  3. テキストボックスに英語で書く（3語以上で提出ボタン有効化）
  4. 「できたら提出!📮」をタップ
  5. **お手本の答え**が表示される → 自分の答えと比較
  6. **セルフチェックリスト**（3項目）にチェック:
     - 5〜15語を目標に、短い英文を書いた
     - 大文字とピリオドを忘れていない
     - スペルをていねいにチェックした
  7. チェックが2個以上 → 正解扱い
- **コイン**: 5 + チェック数 × 5（最大20コイン）
- **注意**: お花屋さんの不正解は復習リストに**入らない**

**3・4級（読解）**:

- **形式**: 掲示・メール・物語の英文を読んで、内容についての4択問題に答える
- **1セッションあたり1つの文章**（建物レベルに応じて2問・3問・5問）
- レベル2・3では英文が長くなり、設問数も増える
- 不正解は復習リストに入り、復習では同じ文章が表示される

**3級・準2級・2級・準1級（英作文・本番形式・さくぶん工房）**:

- **形式**: 実際の英検と同様、意見文を書く（3級: 25〜50語、準2級: 50〜80語、2級: 80〜100語、準1級: 120〜150語）。3つの観点（POINTS）を参考に、考えと理由2つを書く
- **要約（準2級・2級のみ）**: 英文を読んで内容を指定語数（準2級: 25〜35語、2級: 45〜55語）でまとめる。要点を自分の言葉で書くセルフチェック付き
- **1セッションあたり1問**。お手本の答えとの比較＋セルフチェック（3項目・2個以上で正解扱い）は5級と同様
- **注意**: 英作文・要約の不正解は復習リストに**入らない**（5級と同様）

**準2級・2級（要約・本番形式・まとめ塾）**:

- **形式**: 英文を読んで内容を指定語数（準2級: 25〜35語、2級: 45〜55語）でまとめる
- **1セッションあたり1問**。お手本の答えとの比較＋セルフチェック（要点を自分の言葉で書けたか等、3項目・2個以上で正解扱い）
- **注意**: 要約の不正解は復習リストに**入らない**

## 8. 復習システム（📖）

### 8.1 復習リストへの登録

- 通常クイズで不正解になった問題（英作文以外）が自動的に復習リストに追加される
- 重複登録はしない
- 復習リストの問題が正解で解除されると、新しい問題が自動的に補充されることはない（不正解時に蓄積される）

### 8.2 復習クイズ

- 🗼 復習タワーをタップ（ふくしゅうは復習タワーからのみ開始できる）
- 復習リストからランダムに最大5問出題
- 正解すると復習リストから除去される
- 復習クイズでの正解は **4コイン** 固定
- バッジに復習待ちの問題数が表示される

## 12. セーブ・データ管理

### 12.1 自動保存

- クイズの回答、建物の建設・撤去・レベルアップ、道路の設置、かざりの配置・撤去、街の名前変更など、すべての操作後に自動保存
- ブラウザの localStorage に保存（キー: `eikenTownSave_v1`、データ形式 v5）
- **級ごとに別の街**として保存され、級の選択状態も記録される

### 12.2 保存データの内容

```
- 練習中の級（5級 / 4級 / 3級 / 準2級 / 2級）
- 級ごとの街データ:
  - 街の名前
  - 所持コイン
  - 建物の配置（場所・レベル）
  - 建物ごとの正解数（進捗）
  - 道路の配置
  - 復習リスト（未正解の問題ID）
  - 総正解数・総回答数
  - 効果音設定
  - グラフィック設定
```

### 12.3 他ブラウザへの引継ぎ

- 設定（⚙️）の「💾 セーブをファイルに保存」で全級分のデータをJSONファイル（`eiken-town-save.json`）に書き出せる
- 別のブラウザでは「📂 ファイルから読み込む」でファイルを選択。今の全ての級のデータがファイル内容で上書きされる（確認ダイアログあり）
- 形式が正しくないファイルは取り込まず、現在のデータは変更されない

### 12.4 エラー時の挙動

- **保存に失敗した場合**: 警告を表示し、画面上のデータは消さずに保持。「保存を再試行」で再保存できる
- **読み込みに失敗した場合**（破損・未対応形式など）: 警告を表示し、保存データは消さずに保持。「保存を再試行」で再読み込みできる
- 旧形式（v1〜v4）のセーブデータは自動的に新形式へマイグレーションされる（建物の配置・復習リストも引き継ぎ）

### 12.5 注意点

- **同じブラウザ内のみ**で有効（プライベートモードでは保存されない場合がある）
- ブラウザのデータ消去で全消去される
- 「💾 データをけして最初から」で手動リセット可能

## 16. 制限・注意点

1. **1建物1種類**: 図書館を2つ建てる等はできない
2. **解放順**: 建物は 図書館→学校→カフェ→駅→公園→お花屋さん の順にしか建てられない
3. **バージョン**: 現在のデータバージョンは v5（旧バージョン v1〜v4 からのマイグレーション対応済み）
4. **グリッド**: 11×11 = 121 マス（建物6つ・3級は7つ・準2級・2級は8つ・準1級は8つ + 道路 + かざりで消費。旧9×9のセーブデータは自動で移行される）
5. **カメラ制限**: ズーム範囲は 10〜42、回転角は制限あり
6. **TTS非対応ブラウザ**: 一部のブラウザではリスニング問題の音声が再生されない（代わりに文章表示）
7. **WebGL非対応ブラウザ**: 3Dシーンが表示されず、2Dグリッドにフォールバック
8. **プライベートモード**: localStorageが保存されない場合がある

## 18. トラブルシューティング

| 症状 | 対策 |
|------|------|
| 3Dシーンが表示されない | WebGL非対対応の可能性。2Dグリッドで操作可能 |

| ゲームが重い | 設定→「軽いモード」に切替 |
| コインが足りない | 正解を重ねてコインを貯める。道路ボーナスを活用 |
