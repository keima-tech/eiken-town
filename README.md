# えいけんタウン

> **英検4級クエスト** — クイズに答えて、街を育てよう!

単一の HTML ファイルで完結する、英検4級対策と街づくりが融合したブラウザゲームです。

---

## 1. 概要

- **タイトル**: えいけんタウン | 英検4級クエスト
- **形式**: 単一 HTML ファイル（外部不要、ブラウザで開くだけ）
- **対象**: 英検4級レベルの学習者（小学生〜中学生向け）
- **コンセプト**: 英検4級の6分野（たんご・ぶんぽう・かいわ・じゅんじょ・ちょうかい・さくぶん）のクイズに答え、コインを獲得して街を発展させる
- **保存**: ブラウザの localStorage に自動保存（サーバー不要）

---

## 2. はじめかた

### 2.1 開始

1. `eiken-town.html` をブラウザで開く
2. タイトル画面で **「▶️ はじめる!」** をタップ
3. **街の名前をつける** 画面が表示される（最大12文字）
   - サジェストから選ぶことも、自由に入力することもできる
   - 空欄でスキップも可能
4. 6ページのチュートリアルが自動表示される（「スキップ」で飛ばせる）
5. 街画面（scr-town）に移動

### 2.2 継ぎから（再開）

- 保存データがある場合、タイトル画面のボタンが **「▶️ つづきから!」** に変わる
- タップすると前回の状態から再開

## 4. 建物を建てる

### 4.1 建物パレット

**「🏗️ こうじする」** をタップすると、建てられる建物の一覧が表示される。

| 建物 | 絵文字 | カテゴリ | コイン | 解放条件 | クイズ種別 |
|------|--------|----------|--------|----------|------------|
| 図書館 | 📚 | たんご | 無料 | — | 単語・文法の穴埋め選択 |
| 学校 | 🏫 | ぶんぽう | 💰30 | 図書館 | 文法選択クイズ |
| カフェ | ☕️ | かいわ | 💰60 | 学校 | 会話パターン選択 |
| 駅 | 🚉 | じゅんじょ | 💰100 | カフェ | 単語並べ替え |
| 公園 | 🌳 | ちょうかい | 💰150 | 駅 | リスニングクイズ |
| お花屋さん | 🌷 | さくぶん | 💰200 | 公園 | 英作文 |

- **順番に解放**: 図書館→学校→カフェ→駅→公園→お花屋さん（前の建物がないと次の建物はロック）
- **コインが足りない** 場合もロック表示される
- 1種類の建物は最大1つだけ建てられる

### 4.2 道路

- **コスト**: 💰10 / マス
- 建物の上には引けない
- **効果**:
  - 道路に隣接する建物でクイズに正解すると、**追加コイン**がもらえる（隣接建物数 × 2 コイン）
  - 道路がつながるとカラフルな車（最大4台）が走り出す

### 4.3 建設手順

1. 「🏗️ こうじする」をタップ
2. 建物（または道路）を選択
3. 画面下部に「📍を置く場所をタップ!」と表示される
4. 空いているマスをタップ
5. 確認ダイアログで建設を確定（or やめる）
6. 建物が出現し、コインが消費される

> **道路の連続建設**: 道路を選択中は連続タップでどんどん道を引ける

## 5. 建物のレベルアップ

### 5.1 レベル構造

各建物は **Lv.1 → Lv.2 → Lv.3** の3段階。

| レベル移行 | 必要正解数 | 必要コイン | 出題難易度 |
|------------|------------|------------|------------|
| Lv.1 → Lv.2 | 6問 正解 | 💰40 | d=1 のみ → d=1〜2 |
| Lv.2 → Lv.3 | 16問 正解 | 💰100 | d=1〜2 → d=2〜3 |

### 5.2 レベルアップの方法

1. 建物をタップ → メニューが開く
2. 「⬆️ レベルアップする」ボタンが有効になればタップ
3. コインを消費してレベルアップ

> **注意**: 正解数とコインの**両方**が揃っていなければレベルアップできない

### 5.3 難易度の仕組み

- 各問題に難易度（d: 1, 2, 3）が設定されている
- 建物レベルに応じて、出題される難易度の範囲が変わる
- Lv.3 になると難しい問題（d=3）が多く出る

## 6. クイズのルール

### 6.1 基本流れ

1. 建物をタップ → 「▶️ クイズをはじめる!」をタップ
2. **通常クイズ**: 5問出題（お花屋さんの作文のみ2問）
3. 各問に正解 or 不正解で結果が表示
4. 「つぎへ ▶」で次の問題へ
5. 最後に結果画面（scr-result）が表示される

### 6.2 コイン獲得

| 種別 | コイン |
|------|--------|
| 通常正解 | 3 + 2 × 難易度（d=1→5, d=2→7, d=3→9） |
| 連続正解ボーナス | 2回連続から +2 ずつ（最大 +8） |
| パーフェクトボーナス | +10（全問正解 & 3問以上） |
| 道路ボーナス | 隣接建物数 × 2 |
| 復習正解 | 4 コイン固定 |
| 作文（お花屋さん） | 5 + チェック項目数 × 5 |

### 6.3 連続正解（ストリーク）

- 連続で正解すると 🔥 のカウンターが表示される
- 2回以上連続で正解するとボーナスコインが加算
- 不正解でリセットされる

---

## 7. 問題の種類別详解

### 7.1 選択式クイズ（図書館・学校・カフェ）

- **形式**: 英文の空欄を4つの選択肢（A〜D）から選ぶ
- **対象**: たんご（語彙）・ぶんぽう（文法）・かいわ（会話）
- **解き方**:
  1. 問題文を読む（空欄は `_ _` で表示）
  2. 4つの選択肢から正解を選ぶ
  3. 正解 → 緑色のフィードバック + 解説
  4. 不正解 → 赤色のフィードバック + 正解表示 + 解説

### 7.2 単語並べ替えクイズ（駅）

- **形式**: 日本語の文を元に、単語カードを正しい順に並べる
- **解き方**:
  1. 日本語の文を読む
  2. 下の単語カードを順番にタップ → 上のスロットに入る
  3. 入れたカードをタップすると戻せる
  4. 「やりなおす」で全カードをリセット
  5. 全カードを使ったら「これで決定!✔」をタップ
- **判定**: 大文字・句読点は無視して判定（大文字小文字の違いは許容）

### 7.3 リスニングクイズ（公園）

- **2種類ある**:
  - **絵選択式（pic）**: 音声を聞いて、適切な絵（絵文字2つ）を選ぶ（2×2グリッド）
  - **選択式（qa）**: 音声（会話）を聞いて、質問に答える（4択）
- **音声再生**:
  - 🔊 ボタンで音声を再生（自動再生也有り）
  - 何度でも聞ける
  - 難易度に応じて再生速度が変わる（d=1→やや遅め、d=3→標準〜やや速い）
  - **TTS非対応ブラウザ**: 音声が出ない場合、代わりに文章が表示される
- **正解後**: 音声の文章を「🔊 音声の文章をみる」で確認できる

### 7.4 英作文クイズ（お花屋さん）

- **形式**: 英語のトピックに対してエッセイを書く（目標: 15〜25語）
- **1セッションあたり2問**（他の建物は5問）
- **解き方**:
  1. 英語のトピックと日本語の説明を読む
  2. ヒントフレーズを参考にする
  3. テキストボックスに英語で書く（3語以上で提出ボタン有効化）
  4. 「できたら提出!📮」をタップ
  5. **お手本の答え**が表示される → 自分の答えと比較
  6. **セルフチェックリスト**（3項目）にチェック:
     - 15語以上で書いた
     - 大文字とピリオドを忘れていない
     - スペルをていねいにチェックした
  7. チェックが2個以上 → 正解扱い
- **コイン**: 5 + チェック数 × 5（最大20コイン）
- **注意**: お花屋さんの不正解は復習リストに**入らない**

## 8. 復習システム（📖）

### 8.1 復習リストへの登録

- 通常クイズで不正解になった問題（お花屋さんの作文以外）が自動的に復習リストに追加される
- 重複登録はしない

### 8.2 復習クイズ

- 上部バーの 📖 ボタンをタップ
- 復習リストからランダムに最大5問出題
- 正解すると復習リストから除去される
- 復習クイズでの正解は **4コイン** 固定
- バッジに復習待ちの問題数が表示される

## 12. セーブ・データ管理

### 12.1 自動保存

- クイズの回答、建物の建設・レベルアップ、道路の設置、街の名前変更など、すべての操作後に自動保存
- ブラウザの localStorage に保存（キー: `eikenTownSave_v1`）

### 12.2 保存データの内容

```
- 街の名前
- 所持コイン
- 建物の配置（場所・レベル）
- 建物ごとの正解数（進捗）
- 道路の配置
- 復習リスト（未正解の問題ID）
- 総正解数・総回答数
- 効果音設定
- グラフィック設定
```

### 12.3 注意点

- **同じブラウザ内のみ**で有効（プライベートモードでは保存されない場合がある）
- ブラウザのデータ消去で全消去される
- 「💾 データをけして最初から」で手動リセット可能

## 14. 画面サイズ・レスポンシブ対応

- **PC**: 最大幅 1160px、3Dシーンは 430〜900px の高さ
- **モバイル（600px以下）**: ロゴを絵文字に縮小、アイコンボタン縮小、効果音ボタン非表示
- **スマートフォン（480px以下）**: タイトル・パネルのパディング縮小、道路バーのテキスト簡略化
- **タッチデバイス**: 初回起動時に自動で「軽いモード」に設定

## 16. 制限・注意点

1. **1建物1種類**: 図書館を2つ建てる等はできない
2. **解放順**: 建物は 図書館→学校→カフェ→駅→公園→お花屋さん の順にしか建てられない
3. **バージョン**: 現在のデータバージョンは v3（古いバージョンからのマイグレーション対応済み）
4. **グリッド**: 7×7 = 49 マス（建物6つ + 道路で消費）
5. **カメラ制限**: ズーム範囲は 10〜42、回転角は制限あり
6. **TTS非対応ブラウザ**: 一部のブラウザではリスニング問題の音声が再生されない（代わりに文章表示）
7. **WebGL非対応ブラウザ**: 3Dシーンが表示されず、2Dグリッドにフォールバック
8. **プライベートモード**: localStorageが保存されない場合がある

## 18. トラブルシューティング

| 症状 | 対策 |
|------|------|
| 3Dシーンが表示されない | WebGL非対対応の可能性。2Dグリッドで操作可能 |
| 音声が再生されない | TTS非対応ブラウザ。下に表示される文章を確認 |
| データが消えた | プライベートモードの可能性。通常モードで再開 |
| ゲームが重い | 設定→「軽いモード」に切替 |
| コインが足りない | 正解を重ねてコインを貯める。道路ボーナスを活用 |

## 19. 用語集
